# Synchronous FIFO RTL Design and UVM-Based Verification

## Description
Implemented a synchronous FIFO using Verilog HDL to store and retrieve data sequentially using a single clock.

## Features
- Read and write pointer logic
- Full and empty flag detection
- Parameterized FIFO depth and width
- UVM-Based Testbench-based verification

## Tools Used
- Verilog HDL
- SystemVerilog and UVM
- ModelSim
- Cadence Xcelium

## Files
fifo-design.sv – FIFO RTL design  
fifo-testbench.sv – UVM Testbench for verification
fifo-waveform-png - Successfull Read & Write Operation
